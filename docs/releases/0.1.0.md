# Go platform 0.1.0

First platform release: command-line arguments, UTF-8 stdin/stdout/stderr,
application error exit codes, and a Go host for Linux musl, macOS and Windows
MinGW on the supported x86-64 and ARM64 targets.

Download `roc-platform-template-go-examples-0.1.0.zip`, extract it, and run
`roc examples/hello_world/main.roc` from the extracted directory. The examples
name this release's immutable platform bundle and do not pin a compiler.

The platform bundle includes the Go hosts, Roc modules, authenticated linker
inputs and their source/license inventory. Its content-addressed filename is
verified by Roc. The examples archive includes the exact expected stdout,
stderr and exit code for every case in `spec.json`.

PR and release validation cross-compiles all eight target variants, runs them
natively on Linux x64/ARM64, macOS x64/ARM64 and Windows x64, and checks the
examples archive against the same platform bundle before publication. Windows
ARM64 is not supported. The shared nightly tests the immutable released examples
on Linux x64/ARM64, Apple Silicon macOS and Windows x64; Intel macOS and baseline
CPU variants also have dedicated release validation lanes.

Compiler compatibility is reported by the scheduled nightly workflow. A release
is fixed; a compatibility repair requires a new release. This initial release
does not promise compatibility with historical compiler versions.

Every bundle and examples ZIP has SPDX 3.0.1 and CycloneDX 1.7 sidecars and a
manifest binding those inventories to the final SHA-256. The inventory records
all archive members and distinguishes shipped Go/native runtime code from build
tools. MinGW license exceptions and the limits of native closure analysis are
explicit coverage notes; these inventories are not a security certification.
