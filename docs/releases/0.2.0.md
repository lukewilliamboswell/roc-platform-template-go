# Go platform 0.2.0

This release updates the Go host bindings for Roc nightly
`nightly-2026-11-20-3b29392` and builds Linux musl linker inputs for static PIE.

Download `roc-platform-template-go-examples-0.2.0.zip`, extract it, and run
`roc examples/hello_world/main.roc` from the extracted directory. The archive
includes all examples, their expected output and exit codes, and a reference
to this release's immutable platform bundle.

The release publishes SHA-256 checksums and SPDX and CycloneDX inventories for
the platform bundle and examples archive.
